# Glossar / Glossary (DE / EN)

| Deutsch | English | Bedeutung / Meaning |
|---|---|---|
| Ersteinschuss, Initial Margin | initial margin (IM) | Sicherheit gegen den möglichen Verlust bis zur Glattstellung nach einem Ausfall / collateral for potential future exposure until close-out |
| Nachschuss, Variation Margin | variation margin (VM) | täglicher Ausgleich der Marktwertänderung / daily mark-to-market settlement |
| Abwicklungsrisiko-Haltedauer, Liquidationsperiode | margin period of risk (MPOR), liquidation period | Horizont der IM, hier 2 Handelstage / IM horizon, here 2 business days |
| Konfidenzniveau | confidence level | hier 99 % / here 99 % |
| Rückvergleich, Backtesting | backtesting | Vergleich IM mit realisiertem Verlust / IM vs. realised loss |
| Überschreitung | breach, exception | realisierter Verlust > IM / realised loss > IM |
| Ampelansatz (Basel) | (Basel) traffic light | grün 0-4, gelb 5-9, rot ≥ 10 Überschreitungen je 250 Beobachtungen |
| Stresstest | stress test | Ausfallszenarien unter extremen, plausiblen Bedingungen |
| Stressperiode | stress period (SP) | festes historisches Krisenfenster, hier Sep 2021 - Mär 2023 |
| Gefilterte historische Simulation | filtered historical simulation (FHS) | historische Renditen, mit aktueller Volatilität skaliert |
| Volatilitätsuntergrenze | volatility floor | verhindert Volatilität nahe null |
| Prozyklizität | procyclicality | IM steigt in Stressphasen sprunghaft / IM rising sharply in stress |
| Antiprozyklischer Puffer | anti-procyclicality (APC) buffer | ESMA Art. 28 EMIR RTS; bei ECC bis 25 % |
| Diversifikations-, Portfolioeffekt | diversification / offset | Entlastung durch gegenläufige Positionen |
| Grundlast | baseload | Lieferung in allen Stunden / delivery in all hours |
| Spitzenlast | peak load | werktags 8-20 Uhr (nicht im Umfang / out of scope) |
| Lieferzeitraum | delivery period | Monat, Quartal, Jahr / month, quarter, year |
| Lieferstunden | delivery hours | z. B. März 743 h, Oktober 745 h (Zeitumstellung / DST) |
| Kaskadierung | cascading | Jahres-/Quartalskontrakte werden vor Lieferung in kürzere Kontrakte zerlegt |
| Fälligkeit, letzter Handelstag | expiry, last trading day | |
| Abrechnungspreis | settlement price | täglicher Schlusskurs der Börse / exchange daily price |
| Laufzeit, Tenor | tenor (M1, Q1, Y1 …) | relative Fälligkeit / relative maturity |
| Rollen | roll | Wechsel des Kontrakts hinter einem Tenor |
| Konstante Laufzeit | constant maturity | ECC-Konzept für Parameterzeitreihen |
| Preis-Scanning-Range | price scanning range | SPAN-Preisbewegung je Kontrakt (EUR je Lot) |
| Einzel-Margin-Parameter | single margin parameter (SMP) | ECC-Name für die Scanning Range |
| Risikomultiplikator | risk multiplier (R) | Quantilfaktor der normierten Renditen, 2,66-3,5 |
| Intra-Commodity-Spread-Aufschlag | intra-commodity (inter-month) spread charge | |
| Inter-Commodity-Spread-Gutschrift | inter-commodity spread credit | Gutschrift für gegenläufige Positionen verschiedener Tiers |
| Kombinierte Ware | combined commodity | SPAN-Gruppe gleicher Basis, z. B. DEBM |
| Konzentrationsrisiko | concentration risk | große Positionen in illiquiden Märkten (CONR) |
| Liquiditätsaufschlag | liquidity adjustment / add-on | |
| Liquidationsgruppe | liquidation group | Prisma: gemeinsam liquidierbare Produkte |
| Clearingmitglied | clearing member | |
| Zentrale Gegenpartei | central counterparty (CCP) | z. B. ECC |
| Parallelbetrieb | parallel run | ECC: SPAN und Prisma parallel ab 19.10.2026 bis zur Migration im März 2027 |
| Quarantäne (Daten) | quarantine | abgewiesene Rohdatensätze mit Grund |
| Schema-Drift | schema drift | geänderte Spalten einer Quelldatei |
| Day-Ahead-Preis | day-ahead price | Spotauktion für den Folgetag (SMARD) |
| Proxy (Ersatzzeitreihe) | proxy | synthetische Zeitreihe statt echter Futures |
